Відкрий панель з Telegram-кнопки бота
(з ?data=). Прямий захід на URL без параметра — порожній стан.

💾 Як зберегти

Натисни ЗБЕРЕГТИ внизу (або Telegram MainButton). Бот отримає стиснутий payload через tg.sendData і змерджить групи + таймери.

📦 Stock / Monthly плани

Плани boost/monthly живуть у кнопках Telegram-меню бота — у WebApp їх немає через ліміт розміру URL (?data=).

🚀 Redeploy на Vercel

У проєкті Vercel заміни кореневий index.html вмістом з vercel_panel/index.html або версель.txt. URL бота (WEB_APP_URL) не чіпай.

🧠 Smart boost

Для груп 2–5 (і де увімкнено smart_boost) вірусні + % репостів — legacy; накрутка йде з monthly plan. Поле Тижневі перегляди (wv) — опційне.

⏱ Дія «Автодень»

У таймерах є 🚀 Автодень (pipeline) — запускає daily_pipeline.py.
